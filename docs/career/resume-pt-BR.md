## Projeto Prism — bullets (4–6)

- Desenvolvi o **Prism**, sistema local-first em **Next.js/TypeScript** para agregar, normalizar e priorizar vagas com scoring explicável e pipeline de candidaturas.
- Modelei dados e persistência com **Drizzle + SQLite/libSQL**, incluindo índices e seed sintético determinístico para demos.
- Implementei APIs com validação por allowlist, bloqueio de mass assignment e **modo demo somente leitura** para exposição segura.
- Construí motor de scoring por regras (hard gates, skills, localização, red flags) cobertos por testes automatizados.
- Configurei **CI** (lint, typecheck, testes, build) e documentação técnica/ADR para decisões e limitações.
- Organizei UX de decisão: Radar, detalhe de score, Kanban e analytics — stack React 19 + TanStack Query.
